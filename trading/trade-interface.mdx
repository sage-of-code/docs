## Overview

The Trade Terminal is the heart of LiquidLogos. It provides a professional-grade interface for market analysis, order management, and position tracking.

### Terminal Layout

The terminal is organized into five main sections:

1. **Watchlist** — Markets you're monitoring
2. **Chart** — Price action with technical indicators
3. **Order Book** — Real-time buy/sell orders
4. **Trades** — Recent transaction history
5. **Order Ticket** — Entry and position management

## Watchlist

The Watchlist shows markets you're interested in trading.

### Adding to Watchlist

1. Search for a market by name or symbol
2. Click the **★** icon to add it to your watchlist
3. Your watchlist persists across sessions

### Sorting and Filtering

- Sort by price, volume, or change percentage
- Filter by asset class (crypto, stocks, forex, indices)
- Search by symbol or name

## Chart Analysis

### Timeframes

Supported timeframes:
- 1m, 5m, 15m, 1h
- 4h, 1d, 1w, 1M

### Technical Indicators

Draw and customize:
- Moving averages (SMA, EMA)
- MACD, RSI, Bollinger Bands
- Support and resistance levels
- Trend lines

### Chart Tools

- **Zoom** — Scroll to zoom in/out
- **Pan** — Drag to navigate left/right
- **Drawing** — Draw lines, rectangles, and annotations

## Order Book

The order book displays:

- **Buy Orders** — Green side, highest bid first
- **Sell Orders** — Red side, lowest ask first
- **Spread** — Gap between bid and ask

Click on an order size to quickly enter that amount in the order ticket.

## Recent Trades

Displays the last completed trades on the market:

- Trade price
- Trade size
- Direction (buy/sell)
- Timestamp

Use this to understand trading velocity and market sentiment.

## Order Ticket

The order ticket is where you manage entry and exit.

### Opening a Position

1. **Select Direction** — Long (buy) or Short (sell)
2. **Enter Amount** — Collateral to use
3. **Set Leverage** — 1x to 100x (be careful!)
4. **Review** — Check entry price, liquidation price, and fees
5. **Confirm** — Sign in wallet to execute

### Information Displayed

- **Entry Price** — Your position's entry price
- **Liquidation Price** — Price at which position is auto-closed
- **Margin Ratio** — Your safety cushion (100% = liquidation)
- **Est. Fees** — Estimated trading and holding fees

### Keyboard shortcuts

You can use keyboard shortcuts in the Trade Terminal order ticket to move faster.

<Note>
	Shortcuts are ignored while your cursor is inside an input field (amount, price, TP/SL) so typing does not trigger actions.
</Note>

| Key | Action |
| :--- | :--- |
| `B` | Set side to **Buy / Long** |
| `S` | Set side to **Sell / Short** |
| `L` | Switch to **Limit** order |
| `M` | Switch to **Market** order |
| `A` | Switch to **Advanced** order |
| `P` | Toggle **Take Profit / Stop Loss** |
| `1` to `6` | Set leverage preset (`1x`, `2x`, `3x`, `5x`, `10x`, `15x`) |
| `Enter` | Submit the current order (when submit is enabled) |

### Closing a Position

1. Open your Positions page
2. Find the position you want to close
3. Click **Close** or **Close Partial**
4. Confirm the transaction

## Advanced Features

### Order Types

- **Market Order** — Execute immediately at current market price
- **Limit Order** — Execute only at your specified price
- **Stop Order** — Execute when price reaches a trigger level

### Take-Profit and Stop-Loss

After opening a position, you can set:

- **Take-Profit** — Automatically close at a profit target
- **Stop-Loss** — Automatically close to limit losses

These execute as market orders when triggered.

### Position Sizing

- Adjust collateral amount to change position size
- Leverage multiplies your position size
- Position size = Collateral × Leverage

Always review your liquidation price before entering.

## Tips and Tricks

1. **Start with 1x leverage** while learning the interface
2. **Use the chart** to identify support and resistance levels
3. **Monitor spread** — Wider spreads mean higher slippage
4. **Check volume** — Higher volume markets have better execution
5. **Watch funding rates** — They affect your holding costs

## Mobile Trading

LiquidLogos is responsive and works on mobile devices. The terminal adapts to smaller screens with:

- Stacked layout
- Touch-optimized buttons
- Simplified order entry

For serious trading, desktop is recommended.

## Common Issues

**Chart not loading?**
Check your internet connection and refresh the page.

**Orders rejected?**
Ensure you have sufficient collateral and your margin ratio is healthy.

**Slippage too high?**
Try trading during peak liquidity hours or on more liquid markets.

For more help, check the [Risk Management](/positions/overview) guide.
